# 🔑 Настройка Hugging Face API для генерации карточек

## 📋 Что нужно сделать

Для работы генерации карточек через Hugging Face Inference API нужно:
1. Получить бесплатный API ключ
2. Добавить его в переменные окружения Vercel
3. Задеплоить проект

## 🚀 Шаг 1: Получение API ключа Hugging Face

### 1.1 Регистрация на Hugging Face

1. Откройте https://huggingface.co/join
2. Зарегистрируйтесь через:
   - Email
   - GitHub
   - Google

### 1.2 Создание API токена

1. После входа перейдите в настройки:
   - Кликните на аватар в правом верхнем углу
   - Выберите **"Settings"**
   - Или перейдите напрямую: https://huggingface.co/settings/tokens

2. Создайте новый токен:
   - Нажмите **"Create new token"**
   - **Name:** `WB Analytics Card Creator` (любое понятное имя)
   - **Type:** Выберите **"Read"** (достаточно для генерации изображений)
   - Нажмите **"Create token"**

3. Скопируйте токен:
   - Токен начинается с `hf_`
   - **Важно:** скопируйте его сразу, он показывается только один раз!
   - Пример: `hf_abc123xyz456...`

### 1.3 Проверка доступа к моделям

Hugging Face предоставляет бесплатный доступ к моделям:
- ✅ `stabilityai/stable-diffusion-xl-base-1.0` (основная)
- ✅ `runwayml/stable-diffusion-v1-5` (альтернативная)
- ✅ `prompthero/openjourney` (резервная)

**Примечание:** Некоторые модели могут требовать принятия условий использования. Если получите ошибку доступа, откройте страницу модели и нажмите "Agree and access repository".

## 🔧 Шаг 2: Добавление API ключа в Vercel

### 2.1 Через Vercel Dashboard

1. Откройте https://vercel.com/dashboard
2. Выберите ваш проект `analitik-wb`
3. Перейдите в **Settings** → **Environment Variables**
4. Добавьте новую переменную:
   - **Name:** `VITE_HF_API_KEY`
   - **Value:** `hf_ваш_токен_здесь`
   - **Environment:** Выберите все (Production, Preview, Development)
5. Нажмите **"Save"**

### 2.2 Через Vercel CLI (альтернатива)

Если используете Vercel CLI:

```bash
# Перейдите в папку проекта
cd wb-analytics

# Добавьте переменную окружения
vercel env add VITE_HF_API_KEY

# Вставьте ваш токен когда prompted
hf_ваш_токен_здесь

# Выберите окружения (Production, Preview, Development)
```

### 2.3 Локальная разработка

Для локальной разработки создайте файл `.env.local` в корне проекта:

```env
VITE_HF_API_KEY=hf_ваш_токен_здесь
```

**Важно:** Файл `.env.local` уже добавлен в `.gitignore` и не будет загружен в Git.

## 🧪 Тестирование API

### Проверка работы API ключа

Можно проверить работу API через curl:

```bash
curl https://api-inference.huggingface.co/models/stabilityai/stable-diffusion-xl-base-1.0 \
  -X POST \
  -H "Authorization: Bearer hf_ваш_токен_здесь" \
  -H "Content-Type: application/json" \
  -d '{"inputs": "luxury cosmetics photography, marble surface, soft pink lighting"}' \
  --output test.jpg
```

Если всё работает, файл `test.jpg` будет создан с сгенерированным изображением.

### Проверка в браузере

1. Откройте DevTools (F12)
2. Перейдите во вкладку **Console**

## 🔍 Решение проблем

### Проблема: "API ключ Hugging Face не настроен"

**Причина:** Переменная окружения `VITE_HF_API_KEY` не добавлена

**Решение:**
1. Откройте Vercel Dashboard
2. Settings → Environment Variables
3. Добавьте `VITE_HF_API_KEY` с вашим токеном
4. Пересоздайте деплой

### Проблема: "Модель не сработала: 401"

**Причина:** Неверный API ключ или токен истёк

**Решение:**
1. Проверьте правильность токена
2. Убедитесь что токен активен в Settings → Tokens
4. Создайте новый токен если нужно
5. Обновите переменную окружения

### Проблема: "Модель не сработала: 403"

**Причина:** Нет доступа к модели

**Решение:**
1. Откройте страницу модели на Hugging Face
2. Например: https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0
3. Нажмите **"Agree and access repository"**
4. Примите условия использования
5. Попробуйте снова

### Проблема: "Модель не сработала: 503"

**Причина:** Модель загружается или перегружена

**Решение:**
1. Подождите 1-2 минуты
2. Попробуйте снова
3. Система автоматически переключится на другую модель

### Проблема: Генерация занимает слишком долго

**Причина:** Бесплатный тариф имеет приоритет ниже платного

**Решение:**
1. Подождите (может занять до 2 минут)
2. Попробуйте в другое время (меньше нагрузка)
3. Рассмотрите переход на Hugging Face Pro ($9/мес)

## 🎯 Оптимизация промптов

### Лучшие практики

**Хорошие промпты:**
```
✅ luxury cosmetics photography, marble surface, soft pink lighting, premium beauty, studio shot, 8k, high-end, minimalist, featuring cream, natural ingredients
```

**Плохие промпты:**
```
❌ крем для лица увлажняющий с гиалуроновой кислотой для сухой кожи натуральные ингредиенты гипоаллергенный
```

### Почему английские промпты работают лучше

1. Модели обучены преимущественно на английских данных
2. Транслитерация кириллицы работает, но менее точно
3. Короткие промпты генерируются быстрее
4. Ключевые слова важнее полных описаний

### Структура идеального промпта

```
[стиль] + [объект] + [фон] + [освещение] + [качество] + [детали товара]

Пример:
luxury cosmetics photography + cream + marble surface + soft pink lighting + 8k + natural ingredients
```
