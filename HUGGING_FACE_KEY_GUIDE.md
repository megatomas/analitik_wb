# 🔑 Как создать ключ Hugging Face и куда его вставить

## 📋 Пошаговая инструкция

### Шаг 1: Регистрация на Hugging Face

1. Откройте https://huggingface.co/join
2. Выберите способ регистрации:
   - **Email** - введите email и пароль
   - **GitHub** - войдите через GitHub аккаунт
   - **Google** - войдите через Google аккаунт
3. Подтвердите email (если регистрировались по email)
4. Завершите регистрацию

### Шаг 2: Создание API токена

1. После входа перейдите в настройки токенов:
   - Кликните на аватар в правом верхнем углу
   - Выберите **"Settings"**
   - В левом меню выберите **"Access Tokens"**
   - Или перейдите напрямую: https://huggingface.co/settings/tokens

2. Создайте новый токен:
   - Нажмите кнопку **"Create new token"**
   - Заполните форму:
     - **Token Name:** `WB Analytics Card Creator` (любое понятное имя)
     - **Role:** Выберите **"Read"** (достаточно для генерации изображений)
     - **Description:** (необязательно) `Token for WB Analytics card generation`
   - Нажмите **"Create token"**

3. Скопируйте токен:
   - Токен появится в списке
   - Токен начинается с `hf_`
   - Пример: `hf_abc123xyz456def789...`
   - **ВАЖНО:** Скопируйте токен сразу! Он показывается только один раз.
   - Если потеряли токен, создайте новый

### Шаг 3: Куда вставить API ключ

#### Вариант 1: Vercel Dashboard (рекомендуется для продакшена)

1. Откройте https://vercel.com/dashboard
2. Выберите ваш проект `analitik-wb`
3. Перейдите в настройки:
   - Кликните на вкладку **"Settings"**
   - В левом меню выберите **"Environment Variables"**

4. Добавьте новую переменную:
   - **Name:** `VITE_HF_API_KEY` (точно так, с префиксом VITE_)
   - **Value:** `hf_ваш_токен_здесь` (вставьте скопированный токен)
   - **Environment:** Выберите все три окружения:
     - ✅ Production
     - ✅ Preview
     - ✅ Development
   - Нажмите **"Save"**

5. Пересоздайте деплой:
   - Перейдите на вкладку **"Deployments"**
   - Найдите последний деплой
   - Кликните на три точки справа
   - Выберите **"Redeploy"**
   - Подождите 1-2 минуты

#### Вариант 2: Локальная разработка (.env.local)

Для локальной разработки создайте файл `.env.local` в корне проекта:

```bash
# В корне проекта wb-analytics создайте файл
touch .env.local
```

Откройте файл `.env.local` и добавьте:

```env
VITE_HF_API_KEY=hf_ваш_токен_здесь
```

**Важно:**
- Файл `.env.local` уже добавлен в `.gitignore`
- Он не будет загружен в Git
- После создания файла перезапустите dev сервер: `npm run dev`

#### Вариант 3: Vercel CLI (для продвинутых пользователей)

Если используете Vercel CLI:

```bash
# Установите Vercel CLI если ещё не установлен
npm i -g vercel

# Войдите в аккаунт
vercel login

# Добавьте переменную окружения
vercel env add VITE_HF_API_KEY

# Вставьте токен когда prompted
> hf_ваш_токен_здесь

# Выберите окружения (используйте стрелки и пробел)
> Production
> Preview  
> Development

# Пересоздайте деплой
vercel --prod
```

### Шаг 4: Проверка работы

1. Откройте ваш сайт: https://analitik-wb.vercel.app
2. Перейдите во вкладку **"Создание карточек"**
3. Загрузите фото товара
4. Должно появиться сообщение:
   ```
   ✅ Фото проанализировано!
   Категория: cosmetics and beauty products
   Уверенность: 87.3%
   Рекомендуемый стиль: Косметика
   ```
5. Выберите стиль (или используйте предложенный)
6. Добавьте информацию о товаре
7. Нажмите **"Создать карточку"**
8. Подождите 30-120 секунд
9. Готово! Карточка создана

## 🔍 Решение проблем

### Проблема: "API ключ Hugging Face не настроен"

**Причина:** Переменная окружения `VITE_HF_API_KEY` не добавлена или добавлена неправильно.

**Решение:**
1. Проверьте что переменная называется именно `VITE_HF_API_KEY` (с префиксом VITE_)
2. Убедитесь что токен начинается с `hf_`
3. Проверьте что выбраны все окружения (Production, Preview, Development)
4. Пересоздайте деплой после добавления переменной

### Проблема: "Ошибка анализа изображения: 401"

**Причина:** Неверный API ключ или токен истёк.

**Решение:**
1. Откройте https://huggingface.co/settings/tokens
2. Проверьте что токен активен
3. Если токен не работает, создайте новый
4. Обновите переменную окружения в Vercel
5. Пересоздайте деплой

### Проблема: "Ошибка анализа изображения: 403"

**Причина:** У токена нет прав на использование модели.

**Решение:**
1. Откройте страницу модели: https://huggingface.co/openai/clip-vit-base-patch32
2. Нажмите **"Agree and access repository"**
3. Примите условия использования
4. Попробуйте снова

### Проблема: Анализ занимает слишком долго

**Причина:** Бесплатный тариф имеет ограничения по скорости.

**Решение:**
1. Это нормально - анализ может занять 10-30 секунд
2. Попробуйте в другое время (меньше нагрузка на серверы)
3. Рассмотрите переход на Hugging Face Pro ($9/мес) для ускорения

## 📊 Что делает анализ изображения

### Как это работает

1. **Загрузка фото** - вы загружаете фото товара
2. **Отправка на анализ** - фото отправляется в модель CLIP
3. **Zero-shot классификация** - модель определяет категорию товара
4. **Выбор стиля** - автоматически выбирается подходящий стиль
5. **Создание промпта** - формируется промпт для генерации карточки

### Модели которые используются

**Для анализа изображения:**
- **Модель:** `openai/clip-vit-base-patch32`
- **Задача:** Zero-shot image classification
- **Время:** 10-30 секунд
- **Стоимость:** Бесплатно

**Для генерации карточки:**
- **Модель:** `stabilityai/stable-diffusion-xl-base-1.0`
- **Задача:** Text-to-image generation
- **Время:** 30-120 секунд
- **Стоимость:** Бесплатно

### Категории которые определяются

Модель определяет одну из 12 категорий:

1. **cosmetics and beauty products** → Стиль "Косметика"
2. **electronics and gadgets** → Стиль "Электроника"
3. **fashion clothing and accessories** → Стиль "Одежда"
4. **food and beverages** → Стиль "Продукты питания"
5. **sports equipment** → Стиль "Спорт"
6. **home and garden items** → Стиль "Дом и сад"
7. **automotive parts and accessories** → Стиль "Автотовары"
8. **children toys and products** → Стиль "Детские товары"
9. **luxury premium items** → Стиль "Премиум"
10. **eco-friendly organic products** → Стиль "Эко товары"
11. **technology and innovation** → Стиль "Технологии"
12. **minimalist simple design** → Стиль "Минимализм"

### Точность анализа

- **Высокая точность (>80%):** Для товаров с чёткой категорией
- **Средняя точность (60-80%):** Для товаров на границе категорий
- **Низкая точность (<60%):** Для сложных или неоднозначных товаров

**Совет:** Вы всегда можете вручную выбрать другой стиль после анализа.

## 💡 Советы по использованию

### Для лучшего результата анализа

1. **Качественное фото** - чёткое, хорошо освещённое
2. **Товар в центре** - занимающий большую часть кадра
3. **Простой фон** - без лишних деталей
4. **Один товар** - не несколько товаров в кадре

### Если анализ определил неправильно

1. Не переживайте - это нормально
2. Просто выберите правильный стиль вручную на шаге 2
3. Анализ - это только рекомендация, не обязательное действие

### Оптимизация промпта

После анализа вы можете:
1. Добавить название товара (транслитерируется автоматически)
2. Добавить особенности товара
3. Промпт автоматически оптимизируется для лучшего результата
