# 🔧 Решение проблемы: "Не удалось загрузить данные"

## Почему это происходит?

Серверные функции (`api/wb-sales.ts`, `api/wb-stocks.ts`) требуют **отдельного деплоя на Vercel**. Они не работают в статическом режиме.

## ✅ Решение (3 шага)

### Шаг 1: Запушьте код на GitHub

```bash
git add .
git commit -m "Add WB API server functions"
git push
```

### Шаг 2: Дождитесь деплоя на Vercel

После push Vercel автоматически:
- Задеплоит фронтенд (React)
- Задеплоит серверные функции (api/*.ts)
- Это занимает 1-3 минуты

### Шаг 3: Проверьте в Vercel Dashboard

1. Откройте [vercel.com/dashboard](https://vercel.com/dashboard)
2. Выберите ваш проект
3. Перейдите во вкладку **"Functions"**
4. Убедитесь что функции `wb-sales` и `wb-stocks` появились

Если функций нет — проверьте логи деплоя на наличие ошибок.

---

## 🧪 Альтернатива: Работа в демо-режиме

Если серверные функции не развернулись, сервис автоматически переключается в **демо-режим**:
- Показываются демо-данные (не реальные)
- Можно посмотреть интерфейс и функционал
- Вверху будет жёлтый баннер "Демо-режим"

Это нормально для тестирования!

## 🔍 Проверка работы API

### Тест 1: Откройте URL функции напрямую

В браузере откройте:
```
https://ваш-домен.vercel.app/api/wb-sales
```

**Ожидаемый ответ:**
```json
{"error":"API ключ не предоставлен"}
```

Если видите это — функция работает! ✅

**Если видите 404** — функция не задеплоилась ❌

### Тест 2: Проверьте логи

В Vercel Dashboard → Functions → выберите функцию → вкладка "Logs"

Там должны быть сообщения:
```
[wb-sales] Получен запрос
[wb-sales] API ключ не предоставлен
```

## ⚠️ Частые проблемы

### 1. Функции не появляются в Vercel

**Причина:** Vercel не видит папку `api/`

**Решение:**
- Убедитесь что файлы лежат в корне проекта: `/api/wb-sales.ts`
- Проверьте `vercel.json` в корне проекта
- Пересоздайте деплой: Vercel Dashboard → Redeploy

### 2. Ошибка 401 "API ключ не предоставлен"

**Причина:** Фронтенд не передаёт ключ

**Решение:**
- Убедитесь что API-ключ введён в настройках
- Проверьте что ключ начинается с `eyJ...`
- Попробуйте ввести ключ заново

### 3. Ошибка 403 от WB API

**Причина:** У ключа нет нужных прав

**Решение:**
- Создайте новый ключ в кабинете WB
- Отметьте категории: **Статистика** + **Товары**
- Уровень доступа: **Только чтение**

### 4. Ошибка CORS

**Причина:** Браузер блокирует запрос

**Решение:**
- Проверьте `vercel.json` — там должны быть CORS headers
- Функции должны возвращать правильные заголовки
