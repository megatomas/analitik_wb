## 🚀 Что нужно сделать

### Шаг 1: Получить API ключ Hugging Face

1. Откройте https://huggingface.co/join
2. Зарегистрируйтесь (Email/GitHub/Google)
3. Перейдите в Settings → Access Tokens
4. Создайте новый токен:
   - Name: `WB Analytics Card Creator`
   - Type: `Read`
5. Скопируйте токен (начинается с `hf_`)

**Важно:** Токен показывается только один раз! Сохраните его сразу.

### Шаг 2: Добавить API ключ в Vercel

1. Откройте https://vercel.com/dashboard
2. Выберите проект `analitik-wb`
3. Settings → Environment Variables
4. Добавьте переменную:
   - **Name:** `VITE_HF_API_KEY`
   - **Value:** `hf_ваш_токен_здесь`
   - **Environment:** Production, Preview, Development
5. Нажмите Save

### Шаг 3: Запушить изменения

```bash
git add .
git commit -m "Integrate Hugging Face API for card generation"
git push origin main
```

### Шаг 4: Дождаться деплоя

Vercel автоматически:
1. Обнаружит новые изменения
2. Добавит переменную окружения
3. Задеплоит обновлённую версию
4. Через 1-2 минуты сайт будет обновлён

### Шаг 5: Протестировать

1. Откройте https://analitik-wb.vercel.app
2. Перейдите во вкладку "Создание карточек"
3. Загрузите фото товара
4. Выберите стиль (например, "Косметика")
5. Добавьте информацию (название, цена, особенности)
6. Нажмите "Создать карточку"
7. Подождите 30-120 секунд
8. Готово! Карточка создана

## 🔍 Решение проблем

### Проблема: "API ключ Hugging Face не настроен"

**Решение:**
1. Проверьте что добавили `VITE_HF_API_KEY` в Vercel
2. Убедитесь что токен начинается с `hf_`
3. Пересоздайте деплой

### Проблема: "Модель не сработала: 401"

**Решение:**
1. Проверьте правильность токена
2. Убедитесь что токен активен
3. Создайте новый токен если нужно

### Проблема: "Модель не сработала: 403"

**Решение:**
1. Откройте страницу модели на Hugging Face
2. Нажмите "Agree and access repository"
3. Примите условия использования

### Проблема: Генерация занимает слишком долго

**Решение:**
1. Это нормально для бесплатного тарифа (30-120 сек)
2. Попробуйте в другое время (меньше нагрузка)
3. Рассмотрите переход на Hugging Face Pro ($9/мес)
