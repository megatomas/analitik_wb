# 🎨 Создание карточек товаров с ИИ

## ✅ Что реализовано

Создан новый функционал для создания продающих карточек товаров с автоматической обработкой фото через ИИ.

### Основные возможности:

1. **Загрузка фото**
   - Поддержка загрузки с телефона и компьютера
   - Проверка размера (до 10 МБ)
   - Проверка формата (JPG, PNG)

2. **ИИ обработка фото**
   - Автоматическая адаптация под требования WB
   - Размер: 900x1200 пикселей (3:4)
   - Улучшение контраста и насыщенности
   - Выбор фона (белый, градиент)

3. **Соответствие требованиям WB**
   - Минимальный размер: 900x1200 px
   - Соотношение сторон: 3:4
   - Формат: JPEG
   - Готово к загрузке на WB

4. **Скачивание готовой карточки**
   - Одним кликом
   - Автоматическое имя файла
   - Высокое качество (95%)

## 🤖 Для реальной ИИ обработки

Чтобы добавить полноценную ИИ обработку (удаление фона, улучшение качества), нужно интегрировать внешние API:

### Вариант 1: Remove.bg API
**Что делает:** Удаляет фон с фото  
**Стоимость:** ~$0.05 за изображение  
**Документация:** https://www.remove.bg/api

```typescript
// Пример интеграции
const removeBackground = async (imageBase64: string) => {
  const response = await fetch('https://api.remove.bg/v1/remove-bg', {
    method: 'POST',
    headers: {
      'X-API-Key': 'YOUR_REMOVE_BG_API_KEY',
    },
    body: JSON.stringify({
      image: imageBase64,
      size: 'auto',
      type: 'auto',
    }),
  });
  
  return response.json();
};
```

### Вариант 2: Clipdrop API (Stability AI)
**Что делает:** Удаление фона, увеличение качества, удаление объектов  
**Стоимость:** От $9/мес  
**Документация:** https://clipdrop.co/apis

### Вариант 3: Cloudinary AI
**Что делает:** Автоматическое улучшение, удаление фона, генерация  
**Стоимость:** Бесплатный тариф + pay-as-you-go  
**Документация:** https://cloudinary.com/documentation/ai_and_generative_features

### Вариант 4: OpenAI DALL-E / GPT-4 Vision
**Что делает:** Генерация описаний, улучшение фото  
**Стоимость:** По токенам  
**Документация:** https://platform.openai.com/docs

## 🔌 Как интегрировать ИИ API

### Шаг 1: Выберите сервис
Рекомендую **Remove.bg** для удаления фона - простой и надежный.

### Шаг 2: Получите API ключ
Зарегистрируйтесь на https://www.remove.bg/api и получите ключ.

### Шаг 3: Добавьте переменную окружения
В Vercel Dashboard → Settings → Environment Variables:
```
VITE_REMOVE_BG_API_KEY=your_api_key_here
```

### Шаг 4: Обновите код
Замените функцию `processImage` в `CardCreator.tsx`:

```typescript
const processImage = async () => {
  if (!selectedImage) return;

  setIsProcessing(true);
  setError(null);

  try {
    // 1. Удаляем фон через Remove.bg
    const bgRemoved = await removeBackground(selectedImage);
    
    // 2. Создаем canvas для финальной обработки
    const canvas = document.createElement('canvas');
    const ctx = canvas.getContext('2d');
    
    canvas.width = 900;
    canvas.height = 1200;
    
    // 3. Добавляем белый фон
    ctx.fillStyle = '#FFFFFF';
    ctx.fillRect(0, 0, 900, 1200);
    
    // 4. Загружаем изображение без фона
    const img = new Image();
    img.src = bgRemoved.result;
    await new Promise(resolve => {
      img.onload = resolve;
    });
    
    // 5. Размещаем изображение по центру
    const scale = Math.min(800 / img.width, 1000 / img.height);
    const width = img.width * scale;
    const height = img.height * scale;
    const x = (900 - width) / 2;
    const y = (1200 - height) / 2;
    
    ctx.drawImage(img, x, y, width, height);
    
    // 6. Сохраняем результат
    const processedDataUrl = canvas.toDataURL('image/jpeg', 0.95);
    
    setProcessedImage({
      original: selectedImage,
      processed: processedDataUrl,
      width: 900,
      height: 1200,
    });

  } catch (err: any) {
    setError('Ошибка при обработке: ' + err.message);
  } finally {
    setIsProcessing(false);
  }
};
```

## 📱 Использование на телефоне

Функционал полностью адаптирован для мобильных устройств:

1. Откройте сайт на телефоне
2. Перейдите во вкладку "Создание карточек"
3. Нажмите на область загрузки
4. Выберите "Камера" или "Галерея"
5. Сделайте фото или выберите из галереи
6. Выберите фон
7. Нажмите "Создать карточку с ИИ"
8. Скачайте готовую карточку

## 💡 Советы по созданию карточек

### Для лучших результатов:

1. **Качество фото**
   - Используйте хорошее освещение
   - Избегайте теней
   - Фото должно быть четким

2. **Композиция**
   - Товар должен занимать 70-85% кадра
   - Оставьте отступы сверху и снизу
   - Избегайте обрезанных краев

3. **Фон**
   - Белый фон увеличивает конверсию
   - Градиент подходит для премиум товаров
   - Избегайте пестрых фонов

4. **Товар**
   - Покажите товар с лучшей стороны
   - Уберите лишние объекты
   - Используйте подставку для объемных товаров

## 📊 Требования WB к фото

### Официальные требования:

1. **Размер**
   - Минимум: 900x1200 пикселей
   - Рекомендуется: 1200x1600 пикселей
   - Соотношение: 3:4 (вертикальное)

2. **Формат**
   - JPEG или PNG
   - Размер до 10 МБ
   - RGB цветовое пространство

3. **Качество**
   - Четкое изображение
   - Хорошее освещение
   - Без размытия
   - Без водяных знаков

4. **Содержание**
   - Товар занимает 70-90% кадра
   - Белый фон рекомендуется
   - Без лишних объектов
   - Без текста на фото (кроме размера)

### Рекомендации WB:

✅ Белый фон  
✅ Хорошее освещение  
✅ Несколько ракурсов  
✅ Фото размера/характеристик  
✅ Фото упаковки  

❌ Водяные знаки  
❌ Текст на фото  
❌ Пестрый фон  
❌ Низкое качество  
❌ Обрезанные края
