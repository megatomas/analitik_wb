# 🎨 Создание карточек как в Aidentika.com

## ✅ Что сделано

Создан новый раздел **"Создание карточек"** по принципу работы Aidentika.com.

### 4 шага создания карточки:

1. **Загрузка фото товара**
   - Загрузите фото с телефона или компьютера
   - Поддержка JPG, PNG до 10 МБ

2. **Выбор концепции** (8 вариантов)
   - 📸 Студийное фото (белый фон)
   - 🎨 Студия с градиентом
   - 🏠 В интерьере (домашняя обстановка)
   - 💼 В офисе
   - 🌆 На улице (городская среда)
   - 🌿 На природе
   - 📐 Flatlay (композиция сверху)
   - ⚪ Минимализм

3. **Добавление инфографики**
   - Название товара
   - Цена
   - Особенности
   - Материал

4. **Результат**
   - Готовая карточка 900x1200 px (3:4)
   - Скачивание в JPEG
   - Готово к загрузке на Wildberries

## 🚀 Как использовать

1. Откройте сайт
2. Перейдите во вкладку **"Создание карточек"** (иконка камеры 📷)
3. Следуйте 4 шагам:
   - Загрузите фото товара
   - Выберите концепцию
   - Добавьте инфографику (необязательно)
   - Скачайте готовую карточку

## 🎯 Как сделать как в Aidentika (с ИИ)

Aidentika использует **генеративный ИИ** для создания профессиональных фото.

### Что нужно для полноценной ИИ генерации:

**Рекомендуемый сервис:** Clipdrop API
- Стоимость: ~$0.009 за карточку
- Качество: Отличное
- Скорость: 10-20 секунд

### Как интегрировать:

1. **Зарегистрируйтесь на Clipdrop**
   - https://clipdrop.co/apis
   - Получите API ключ (100 изображений бесплатно)

2. **Добавьте переменную окружения в Vercel**
   ```
   VITE_CLIPDROP_API_KEY=your_api_key_here
   ```

3. **Создайте серверную функцию**
   - Файл: `api/generate-card.ts`
   - Код в файле `AIDENTIKA_INTEGRATION.md`

4. **Обновите CardCreator.tsx**
   - Замените функцию `processImage`
   - Код в файле `AIDENTIKA_INTEGRATION.md`

5. **Запушьте и задеплойте**
   ```bash
   git add .
   git commit -m "Add AI image generation"
   git push
   ```

### Что будет после интеграции:

✅ Удаление фона с фото  
✅ Генерация реалистичного окружения  
✅ Размещение товара в сцене  
✅ Добавление теней и отражений  
✅ Профессиональное качество как в Aidentika
