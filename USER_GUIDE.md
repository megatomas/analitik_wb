# 📘 Руководство пользователя: WB Analytics Pro

## 🚀 Быстрый старт

### 1. Регистрация
- Перейдите на сайт вашего сервиса
- Нажмите "Регистрация"
- Введите email и пароль (минимум 6 символов)
- Подтвердите email (если требуется)

### 2. Настройка API-ключа Wildberries

После регистрации вы увидите страницу "Подключите Wildberries API".

#### 📋 Пошаговая инструкция:

**Шаг 1: Войдите в личный кабинет WB**
- Откройте [seller.wildberries.ru](https://seller.wildberries.ru)
- Войдите под учётной записью владельца магазина

**Шаг 2: Перейдите в раздел API**
- В верхнем меню выберите "Настройки"
- Нажмите "Доступ к API"

**Шаг 3: Создайте новый токен**

Нажмите кнопку "Создать токен" и заполните параметры:

##### 🔑 Тип токена:
```
Базовый токен
```
Для ручного подключения внешних сервисов

##### 📊 Категории данных (отметьте галочками):

✅ **Статистика** (ОБЯЗАТЕЛЬНО)
- Данные о продажах, заказах, браках
- Необходимо для аналитики продаж

✅ **Товары** (ОБЯЗАТЕЛЬНО)
- Информация об остатках на складах
- Необходимо для рекомендаций по пополнению

⬜ **Контент** (опционально)
- Данные карточек товаров
- Нужно только если хотите анализировать контент

⬜ **Аналитика** (опционально)
- Расширенная аналитика (если доступна в вашем тарифе)

##### 🔒 Уровень доступа:
```
Только чтение
```

⚠️ **ВАЖНО:** НЕ выбирайте "Чтение и запись"!
- Нашему сервису не нужно менять данные в вашем кабинете
- Только чтение безопаснее и достаточно для аналитики

##### 📝 Название токена:
```
WB Analytics Pro
```
Используйте понятное название, чтобы легко найти токен в списке

**Шаг 4: Скопируйте ключ**
- После создания токен показывается только один раз!
- Сразу скопируйте его (длинная строка символов)
- Вставьте в поле на странице настройки

**Шаг 5: Проверка и подключение**
- Нажмите "Проверить и подключить"
- Система проверит валидность ключа
- При успехе вы увидите зелёную галочку
- Нажмите "Продолжить"

### 3. Готово! 🎉

Теперь вы видите реальные данные вашего магазина:
- Продажи за вчера, неделю, месяц
- Рекомендации по пополнению остатков
- ИИ-аналитик с персональными советами
- Графики и аналитика

## 🔐 Безопасность

### Как мы защищаем ваши данные:

1. **API-ключ хранится в зашифрованном виде**
   - Используем шифрование AES-256
   - Ключ недоступен в открытом виде даже нам

2. **Запросы идут через защищённый прокси**
   - Фронтенд не обращается напрямую к WB API
   - Ключ не попадает в браузер пользователя

3. **HTTPS везде**
   - Все данные передаются по защищённому соединению
   - Сертификат Let's Encrypt

4. **Вы контролируете доступ**
   - Можете отозвать токен в любой момент в кабинете WB
   - После отзыва наш сервис потеряет доступ к данным

### Что НЕ нужно делать:

❌ Не передавайте API-ключ третьим лицам
❌ Не публикуйте ключ в открытых источниках (GitHub, чаты, форумы)
❌ Не отправляйте ключ в скриншотах
❌ Не храните ключ в текстовых файлах без шифрования

### Что делать при подозрении утечки:

1. Немедленно отзовите токен в кабинете WB
2. Создайте новый токен
3. Обновите ключ в настройках нашего сервиса
4. Свяжитесь с поддержкой

## 🛠️ Решение проблем

### Ошибка "Неверный API-ключ"

**Возможные причины:**
- Ключ скопирован не полностью
- Ключ отозван или истёк
- Неверные права доступа

**Решение:**
1. Проверьте, что скопировали весь ключ (обычно начинается с `eyJ...`)
2. Убедитесь, что токен активен в кабинете WB
3. Проверьте, что отмечены категории "Статистика" и "Товары"
4. Создайте новый токен и попробуйте снова

### Данные не обновляются

**Возможные причины:**
- WB API временно недоступен
- Превышен лимит запросов
- Проблемы с интернетом

**Решение:**
1. Подождите 5-10 минут и обновите страницу
2. Проверьте статус WB API на [dev.wildberries.ru](https://dev.wildberries.ru)
3. Свяжитесь с поддержкой, если проблема сохраняется

### Не приходят уведомления в Telegram

**Решение:**
1. Убедитесь, что бот запущен
2. Проверьте, что вы написали боту `/start`
3. Проверьте настройки уведомлений в профиле
4. Пересоздайте бота через @BotFather при необходимости
