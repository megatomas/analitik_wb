## 🔍 Как это работает теперь:

### Архитектура:

```
Браузер → Cloudflare Worker → WB API
   ↓
   ├─ GET /api/v1/supplier/sales (продажи)
   └─ POST /api/analytics/v1/stocks-report/wb-warehouses (остатки)
```

### Формат запроса к Worker:

**Для продаж (GET):**
```json
{
  "method": "GET",
  "url": "https://statistics-api.wildberries.ru/api/v1/supplier/sales?dateFrom=2024-01-01",
  "body": null
}
```

**Для остатков (POST):**
```json
{
  "method": "POST",
  "url": "https://seller-analytics-api.wildberries.ru/api/analytics/v1/stocks-report/wb-warehouses",
  "body": {
    "limit": 250000,
    "offset": 0
  }
}
```

### Кэширование:

- ✅ Данные кэшируются на **10 минут**
- ✅ Повторные запросы берутся из кэша
- ✅ Снижается нагрузка на WB API
- ✅ Ошибка 429 больше не появится

## 🆘 Если что-то не работает:

### Ошибка 401 (Неверный ключ)
- Проверьте что используете **персональный токен**
- Убедитесь что токен не отозван

### Ошибка 403 (Нет доступа)
- Проверьте категории токена: **Статистика** + **Аналитика**
- Создайте новый персональный токен

### Ошибка 429 (Превышен лимит)
- Подождите 20 секунд (лимит нового API остатков)
- Данные кэшируются на 10 минут

### Worker не обновился
- Проверьте что нажали **Deploy** в Cloudflare
- Подождите 10-15 секунд
- Обновите страницу сайта
