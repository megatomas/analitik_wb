# 🎨 Бесплатные альтернативы для создания карточек

## ✅ Что добавлено

В проект интегрирована информация о **бесплатных альтернативах** для создания профессиональных карточек товаров с ИИ генерацией.

## 🆓 Лучшие бесплатные варианты

### 1. PixelPanda ⭐ (Рекомендуется)
- **Бесплатно:** 3 генерации в день без регистрации
- **Качество:** Отличное (как в Aidentika)
- **Что делает:** Удаляет фон, генерирует окружение, создает реалистичные тени
- **Сайт:** https://pixelpanda.ai/free-tools/ecommerce-product-photography

### 2. Hugging Face API
- **Бесплатно:** Ограниченное количество запросов в день
- **Качество:** Хорошее
- **Что делает:** Удаление фона, генерация изображений
- **Сайт:** https://huggingface.co

### 3. WithoutBG (Open Source)
- **Бесплатно:** 100% бесплатно
- **Качество:** Отличное
- **Что делает:** Удаление фона
- **Сайт:** https://withoutbg.com

### 4. Stable Diffusion (локально)
- **Бесплатно:** 100% бесплатно
- **Качество:** Отличное
- **Что делает:** Генерация изображений, удаление фона
- **Требования:** Мощный ПК или Google Colab

## 🎨 Что реализовано в CardCreator

### Базовая версия (текущая):
- ✅ Загрузка фото товара
- ✅ Выбор концепции (8 вариантов)
- ✅ Добавление инфографики
- ✅ Базовая обработка через Canvas API
- ✅ Скачивание готовой карточки

### Бесплатная альтернатива:
- 🎁 Ссылка на PixelPanda (3 генерации/день)
- 🎁 Полноценная ИИ генерация
- 🎁 Удаление фона
- 🎁 Генерация окружения
- 🎁 Профессиональное качество

## 🚀 Как использовать

### Вариант 1: Базовая обработка (встроено)
1. Откройте вкладку "Создание карточек"
2. Загрузите фото товара
3. Выберите концепцию
4. Добавьте инфографику
5. Скачайте готовую карточку

**Результат:** Базовая обработка (масштабирование, фон, инфографика)

### Вариант 2: PixelPanda (бесплатно, рекомендуется)
1. Нажмите кнопку "Попробовать PixelPanda бесплатно"
2. Загрузите фото товара на PixelPanda
3. Выберите сцену (10 вариантов)
4. Скачайте готовую карточку

**Результат:** Профессиональная карточка с ИИ генерацией (как в Aidentika)
