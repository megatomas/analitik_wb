# 🎉 Исправлено: Учёт заказов со всех складов

## ✅ Что было исправлено

### Проблема
Раньше использовался старый API endpoint `statistics-api.wildberries.ru/api/v1/supplier/sales` который возвращал только продажи со склада WB. Заказы со склада продавца не учитывались.

### Решение
Переключились на новый **Order Feed API** (`seller-analytics-api.wildberries.ru/api/analytics/v1/order-feed`) который возвращает **все заказы со всех складов** (WB и продавца).

## 📊 Что изменилось

### Старый подход
```typescript
// Только продажи со склада WB
GET https://statistics-api.wildberries.ru/api/v1/supplier/sales?dateFrom=...
```

### Новый подход
```typescript
// Все заказы со всех складов
POST https://seller-analytics-api.wildberries.ru/api/analytics/v1/order-feed
Body: {
  selectedPeriod: { start: ..., end: ... },
  nmIds: [],
  subjectIds: [],
  brandNames: [],
  tagIds: [],
  pagination: { offset: 0, limit: 1000 }
}
```

## 📋 Лимиты API

### Order Feed API
- **Лимит:** 1 запрос в минуту (персональный токен)
- **Период:** максимум 31 день
- **Обновление:** в реальном времени
- **Пагинация:** до 1000 заказов за запрос

### Stocks Report API
- **Лимит:** 3 запроса в минуту (персональный токен)
- **Обновление:** каждые 30 минут
- **Лимит записей:** до 250,000 за запрос

## 💡 Преимущества нового подхода

1. **Полные данные** — учитываются все заказы со всех складов
2. **Реальное время** — данные обновляются мгновенно
3. **Детальная информация** — есть поле `warehouseName` и `isMp`
4. **Статусы заказов** — можно фильтровать по статусу (deliver, cancel, return)
5. **Один API** — все данные из одного источника

## 🔧 Технические детали

### Фильтрация заказов
```typescript
// Считаем только успешные заказы
const successfulOrders = ordersData.filter(
  (o) => o.status !== 'cancel' && o.status !== 'return'
);
```

### Расчёт выручки
```typescript
const revenue = successfulOrders.reduce(
  (sum, o) => sum + (o.sellerPrice || 0),
  0
);
```

### Расчёт скорости продаж
```typescript
// Считаем заказы по товарам за 30 дней
orders.forEach((order: any) => {
  if (order.status === 'cancel' || order.status === 'return') {
    return; // Пропускаем отменённые
  }
  const key = order.nmId;
  if (key) {
    productSales.set(key, (productSales.get(key) || 0) + 1);
  }
});
```
