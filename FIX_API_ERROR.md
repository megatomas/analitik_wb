# 🔧 Решение проблемы с загрузкой данных

## ❌ Проблема: "Превышен лимит запросов WB API"

### Причина
Wildberries API **не поддерживает прямые запросы из браузера** (CORS). Нужен серверный прокси.

---

## ✅ Решение 1: Серверные функции Vercel (правильный способ)

### Шаг 1: Убедитесь что код запушен на GitHub

```bash
git add .
git commit -m "Add Vercel serverless proxy"
git push
```

### Шаг 2: Дождитесь деплоя (2-3 минуты)

Vercel автоматически развернёт серверную функцию из файла `api/wb-proxy.ts`.

### Шаг 3: Проверьте что функция работает

Откройте в браузере:
```
https://analitik-wb.vercel.app/api/wb-proxy
```

**Если видите:**
```json
{"error":"API ключ не предоставлен"}
```
✅ **Функция работает!** Всё хорошо.

**Если видите 404:**
❌ Функция не развернулась. Проверьте логи в Vercel Dashboard.

### Шаг 4: Обновите страницу сайта

Теперь данные должны загружаться через серверный прокси.

## 🔍 Как проверить что всё работает

### Тест 1: Проверьте функцию

Откройте: `https://analitik-wb.vercel.app/api/wb-proxy`

Должен увидеть: `{"error":"API ключ не предоставлен"}`

### Тест 2: Проверьте логи

1. Откройте [Vercel Dashboard](https://vercel.com/dashboard)
2. Выберите проект `analitik-wb`
3. Перейдите во вкладку **Functions**
4. Должна быть функция `wb-proxy`
5. Кликните на неё → вкладка **Logs**
6. Попробуйте загрузить данные на сайте
7. В логах должны появиться запросы

### Тест 3: Откройте консоль браузера

1. Нажмите F12
2. Перейдите во вкладку **Network**
3. Обновите страницу
4. Найдите запрос к `/api/wb-proxy`
5. Проверьте статус:
   - ✅ **200** — всё работает
   - ❌ **404** — функция не развернулась
   - ❌ **429** — лимит WB API (подождите 1-2 минуты)

## ❌ Если серверные функции не работают

### Проблема: Функция 404

**Причина:** Vercel не развернул функцию

**Решение:**

1. Проверьте что файл `api/wb-proxy.ts` есть в репозитории
2. Проверьте что он в корне проекта (не в подпапке)
3. Проверьте `vercel.json` в корне проекта
4. Пересоздайте деплой:
   - Vercel Dashboard → ваш проект
   - Вкладка **Deployments**
   - Нажмите `...` на последнем деплое
   - Выберите **Redeploy**

### Проблема: Ошибка в логах

**Решение:**

1. Откройте логи функции
2. Найдите ошибку
3. Проверьте что установлен пакет `@vercel/node`:
   ```bash
   npm install @vercel/node
   git add package.json package-lock.json
   git commit -m "Add @vercel/node"
   git push
   ```

## 🎯 Альтернативное решение: CORS-прокси (быстрый способ)

Если серверные функции не работают, можно использовать публичный CORS-прокси:

### Вариант 1: corsproxy.io

```typescript
const proxyUrl = 'https://corsproxy.io/?';
const targetUrl = `https://statistics-api.wildberries.ru${endpoint}`;
const response = await fetch(`${proxyUrl}${encodeURIComponent(targetUrl)}`, {
  headers: {
    'Authorization': user.wbApiKey,
  },
});
```

**Минусы:**
- ⚠️ Ненадёжно (публичный сервис)
- ⚠️ Может не передавать заголовки
- ⚠️ Не подходит для продакшна

### Вариант 2: allorigins.win

```typescript
const proxyUrl = 'https://api.allorigins.win/raw?url=';
const targetUrl = `https://statistics-api.wildberries.ru${endpoint}`;
const response = await fetch(`${proxyUrl}${encodeURIComponent(targetUrl)}`);
```

**Минусы:**
- ⚠️ Не передаёт заголовки авторизации
- ⚠️ Не работает с WB API (нужен Authorization header)

### Архитектура:

```

    ↓
    ↓ /api/wb-proxy (Vercel Function)
```

- ✅ Обход CORS ограничений
- ✅ Кэширование на сервере
- ✅ Контроль лимитов
- ✅ Логирование запросов
