# 🔧 Исправление ошибки 500 от Hugging Face API

## ❌ Проблема

**Симптомы:**
- Все модели возвращают ошибку 500 "Внутренняя ошибка сервера"
- Генерация карточек не работает ни с одной моделью
- Ошибка повторяется постоянно

**Причина:**
Модели Stable Diffusion **не поддерживают произвольные размеры** (900x1200) в параметрах запроса. Они работают только со стандартными размерами (512x512, 768x768 и т.д.).

Когда мы передавали `width: 900, height: 1200`, модели возвращали внутреннюю ошибку.

---

## ✅ Что исправлено

### 1. Убраны параметры width/height из запроса

**Было:**
```typescript
body: JSON.stringify({
  inputs: prompt,
  parameters: {
    width: 900,      // ❌ Модели не поддерживают
    height: 1200,    // ❌ Модели не поддерживают
    num_inference_steps: 30,
    guidance_scale: 7.5,
  }
})
```

**Стало:**
```typescript
body: JSON.stringify({
  inputs: prompt,
  parameters: {
    // ✅ Убрали width/height
    // Модели генерируют в стандартном размере
    num_inference_steps: 25,
    guidance_scale: 7.5,
  }
})
```

### 2. Добавлено масштабирование на клиенте

Теперь после получения изображения от API, мы масштабируем его до 900x1200 на клиенте через Canvas:

```typescript
// Масштабируем изображение до 900x1200 (требование WB)
const imgAspectRatio = img.width / img.height;
const canvasAspectRatio = 900 / 1200;

let drawWidth, drawHeight, drawX, drawY;

if (imgAspectRatio > canvasAspectRatio) {
  // Изображение шире - масштабируем по ширине
  drawWidth = 900;
  drawHeight = 900 / imgAspectRatio;
  drawX = 0;
  drawY = (1200 - drawHeight) / 2;
} else {
  // Изображение выше - масштабируем по высоте
  drawHeight = 1200;
  drawWidth = 1200 * imgAspectRatio;
  drawX = (900 - drawWidth) / 2;
  drawY = 0;
}

// Заполняем фон белым цветом
ctx.fillStyle = '#FFFFFF';
ctx.fillRect(0, 0, 900, 1200);

// Рисуем изображение с масштабированием
ctx.drawImage(img, drawX, drawY, drawWidth, drawHeight);
```

### 3. Добавлены более стабильные модели

**Было:**
```typescript
const models = [
  'stabilityai/stable-diffusion-2-1',
  'CompVis/stable-diffusion-v1-4',
  'stabilityai/stable-diffusion-xl-base-1.0'
];
```

**Стало:**
```typescript
const models = [
  'stabilityai/stable-diffusion-2-1-base',  // ✅ Базовая версия без условий
  'CompVis/stable-diffusion-v1-4',          // ✅ Старая но стабильная
  'runwayml/stable-diffusion-v1-5',         // ✅ Альтернативная
  'stabilityai/stable-diffusion-2-1',       // ✅ Полная версия
];
```

## 🔍 Как это работает теперь

### Процесс генерации:

```
1. Пользователь выбирает стиль и добавляет информацию
        ↓
2. Формируется промпт (английский, короткий)
        ↓
3. Запрос к серверному прокси /api/hf-proxy
        ↓
4. Сервер делает запрос к Hugging Face API
   БЕЗ параметров width/height
        ↓
5. Модель генерирует изображение в стандартном размере
   (обычно 512x512 или 768x768)
        ↓
6. Сервер возвращает изображение в base64
        ↓
7. Клиент получает изображение
        ↓
8. Клиент масштабирует изображение до 900x1200
   через Canvas API
        ↓
9. Добавляется инфографика (название, цена)
        ↓
10. Готовая карточка 900x1200 px
```

### Почему это работает:

✅ **Модели работают со стандартными размерами** - не нужно передавать width/height  
✅ **Клиент масштабирует изображение** - используем Canvas API для точного контроля  
✅ **Сохраняются пропорции** - изображение не искажается  
✅ **Белый фон** - заполняем пустое пространство белым цветом  
✅ **Требование WB выполнено** - итоговый размер 900x1200 px

## 🐛 Решение проблем

### Проблема: Ошибка 500 всё ещё появляется

**Причина:** Модель временно недоступна или требует принятия условий

**Решение:**
1. Подождите 1-2 минуты
2. Система автоматически попробует другую модель
3. Если все модели не работают - проверьте логи в Vercel Functions

### Проблема: Изображение имеет белый фон по бокам

**Причина:** Исходное изображение не соответствует пропорциям 3:4

**Решение:**
- Это нормально! Мы заполняем пустое пространство белым цветом
- Изображение не искажается, пропорции сохраняются
- Для лучшего результата используйте квадратные изображения

### Проблема: Качество изображения низкое

**Причина:** Бесплатные модели имеют ограничения

**Решение:**
1. Используйте более детальные промпты
2. Попробуйте другие стили
3. Рассмотрите платные модели (FLUX.1-pro, DALL-E 3)

## 💡 Советы по использованию

### 1. Используйте квадратные изображения

Для лучшего результата загружайте квадратные изображения (1:1). Они лучше масштабируются в формат 3:4.

### 2. Используйте детальные промпты

**Хорошо:**
```
luxury cosmetics photography, marble surface, soft pink lighting, premium beauty, studio shot, 8k, high-end, minimalist
```

**Плохо:**
```
cosmetics
```

### 3. Пробуйте разные стили

Некоторые стили работают лучше с определёнными категориями товаров:
- **Косметика** → стиль "Косметика" или "Премиум"
- **Электроника** → стиль "Электроника" или "Технологии"
- **Одежда** → стиль "Одежда" или "Минимализм"

### 4. Проверяйте логи

Если что-то не работает, проверьте логи в Vercel Functions:
1. Vercel Dashboard → Functions → hf-proxy → Logs
2. Попробуйте создать карточку
3. Посмотрите детали ошибки
